🚀 SkillsFusion – Freelancer Finding Platform


SkillsFusion is a dynamic web platform that connects clients with freelancers across various domains like development, designing, and more. Clients can post their projects, and freelancers can browse, apply, and communicate seamlessly—all in one place!


📌 Features

👤 For Clients

Post projects under specific domains (e.g., development, design)

Receive applications from interested freelancers

Get detailed applicant info via automated email from SkillsFusion base mail

Initiate chats with freelancers to streamline communication

🧑‍💻 For Freelancers

Explore domain-specific projects

Apply to projects with credentials and portfolio

Receive a confirmation email upon successful application

Chat directly with clients for further discussion

✉️ Email Notifications (Automated)

Client Email: Includes applicant details (name, email, profile, project applied)

Freelancer Email: Confirmation that application was sent successfully

Emails are sent from the SkillsFusion base email system

💬 Real-time Chat Feature

To bridge the communication gap, SkillsFusion includes a secure chat system between:

The client who posted the project

The freelancer who applied for the project

This ensures transparent communication, clarification of requirements, and faster onboarding.

⚙️ Tech Stack

Frontend: React.js

Backend: SpringBoot

Database: MYSQL

Email Service: Spring Boot Starter Mail(skillsfusion01@gmail.com)

Authentication: JWT

Chat: Pooling Technique
